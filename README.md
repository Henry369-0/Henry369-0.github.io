# Henry369-0.github.io

刘柏杨的个人主页。

这是一个纯静态 HTML 页面，不需要 Node.js、npm 或构建工具。直接打开 `index.html` 即可预览，推送到 `main` 分支后由 GitHub Pages 发布。

主页内容以个人介绍、教育背景、思考方式、精选内容和联系方式为主，不是第二份简历。

## 文件说明

- `index.html`：完整主页，内容和样式集中在一个文件中；
- `avatar.png`：主页头像；
- `avatar-github.jpg`：适合上传到 GitHub 的头像；
- `.github/workflows/deploy.yml`：静态页面发布配置。
